# Trailbook 移动端前端

基于现有原型编写的 React Native 多页面演示，通过 Expo 在 PC 浏览器运行。没有嵌入原 HTML，没有新增依赖，也还不是能真实规划旅行的完整产品。

## 启动和检查

在本目录执行（从仓库根目录进入：`cd apps/mobile`）：

```powershell
npm run web
```

访问终端显示的地址，通常是 `http://localhost:8081`。指定端口可用 `npm run web -- --port 8081`。修改页面后，开发服务会更新页面；Ctrl+C 停止服务。

已有依赖不必重装。新检出项目可先执行 `npm ci`，按锁文件安装。无需全局安装 Expo、TypeScript 或 pnpm。

```powershell
npm run typecheck
npm test
```

这两个命令分别检查 TypeScript 与表单日期/时间、锁定保护、替换边界、数据副本和存储结构。测试使用 Node 24 自带能力，无额外测试依赖。`npm start` 启动 Expo 开发服务，让你自行选择目标平台；当前只验证 Web。

## 可以怎样体验

1. 首页 → 开始规划旅行 → 填写重庆、日期、到离时间、接驳地点、住宿和兴趣。缺填、无效日期、时间倒置和超过 7 个自然日会提示。
2. 确认信息 → 查看需求摘要。这里明确说明尚未接入真实规划，没有假的 AI 计算进度。
3. 打开独立固定重庆三日样例（2026-10-01 至 10-03），它不会使用你填的日期、酒店或偏好排程。
4. 切换三天和时间线/地点顺序。地图底图、坐标和真实交通不存在；天气显示未知。
5. 打开地点详情，查看演示说明、未核验字段，尝试收藏。
6. 锁定一项活动后，它不能被替换或移除。替换其他活动会保留示例时间；移除需确认，可撤销上一次调整。没有真实局部重排。
7. 保存到本机 → 我的 → 打开保存副本。修改不会自动覆盖已保存内容，需再次主动保存；打开旧副本前会提醒丢弃未保存调整。
8. 发现页可搜索和按体验筛选本地卡片，空结果有清除入口；选择兴趣可带入需求表单。
9. 我的页可查看保存副本、收藏、当前表单偏好，确认删除单个副本或清除本应用演示存储。

## 数据究竟放在哪里

| 内容 | Web 浏览器 | 原生端（尚未验证） |
| --- | --- | --- |
| 需求表单、攻略原文、当前未保存行程 | React 内存，页面跳转保留，刷新丢失 | 当前运行内存 |
| 主动保存的演示副本、收藏 | 当前来源的 `localStorage` | 当前运行内存，未接持久化 |
| 服务器数据、账号、同步 | 没有 | 没有 |

本地存储键是 `trailbook-demo-library-v1`，最多保存 20 份样例。刷新后到“我的”主动重新打开副本；不会自动恢复未保存调整。删除副本不删除当前内存行程。清除浏览器数据、更换端口/浏览器/设备都可能看不到原保存记录，本地存储不代替备份。

读取到损坏或不兼容的数据会暂停保存，不自动覆盖；用户可以在“我的”中确认清除本应用演示存储。写入失败不会显示保存成功。此应用不上传数据、不抓取攻略链接，也不存储任何服务密钥。

## 文件用途

| 文件 | 用途 |
| --- | --- |
| `package.json` | 依赖清单、Expo Router 入口和启动/检查命令 |
| `package-lock.json` | 固定 npm 安装结果，保留并提交，不手工修改 |
| `app.json` | 应用名称、Expo Router 插件和 Web 构建配置 |
| `tsconfig.json` | 继承 Expo 的 TypeScript 配置，开启严格类型检查 |
| `app/_layout.tsx` | 页面公共入口，提供安全区域、状态栏和共享 TravelProvider |
| `app/index.tsx` | 首页路由，显示 HomeScreen |
| `app/plan.tsx` / `app/review.tsx` | 需求输入和信息确认 |
| `app/trip.tsx` / `app/place.tsx` / `app/adjust.tsx` | 行程、地点详情和替换活动 |
| `app/discover.tsx` / `app/me.tsx` | 发现、我的 |
| `app/+not-found.tsx` | 未知路径的返回入口 |
| `src/screens/` | 各页面布局与交互，沿用奶油底色和绿色视觉 |
| `src/components/ui.tsx` | 共享按钮、表单、提示、弹窗、页面外壳与底部导航 |
| `src/state/TravelContext.tsx` | 共享草稿、当前行程、选中日期/视图、保存副本和撤销状态 |
| `src/lib/travel.ts` | 数据类型、固定演示资料、日期校验、活动修改和存储校验；不是规划器 |
| `src/lib/storage.web.ts` / `storage.ts` | 浏览器本地存储 / 原生内存模式适配边界 |
| `src/assets/prototype-photos.ts` | 从原 HTML 原型复用的四张内嵌演示图片，预览不依赖外链 |
| `tests/travel.test.cjs` | 可重复运行的轻量逻辑测试 |

`node_modules` 是本项目依赖，`.expo` 是开发缓存，`dist` 是验证构建的网页产物，均由仓库根目录 `.gitignore` 忽略，不应提交。当前不需要 `.env`。
