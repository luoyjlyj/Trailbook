# 原型与首版范围

这两个 HTML 文件是原有完整产品设想的可点击参考，保留其视觉和交互，不视为全部功能的开发承诺：

- [移动端原型](mobile-prototype.html)
- [运营后台原型](admin-prototype.html)

可以直接在浏览器打开，无需安装依赖。页面内的地点、天气、地图、评分和运营统计是演示内容；保存、导出、审核或服务连接等提示不代表真实后端操作。刷新不会保留页面内的交互状态。

## 移动端

| 原型页面 | 首版如何使用 |
| --- | --- |
| 首页 | 保留创建与继续行程入口，限定一个试点城市 |
| 创建计划 | 保留日期、住宿、偏好；补齐真实到离时间、接驳地点和输入检查 |
| AI 生成方案 | 作为生成状态样式参考，实际规划由程序执行，模型辅助后接入 |
| 每日行程 | 核心页面，使用后端返回的真实结构化数据 |
| 行程地图视图 | 核心页面，需要真实地图 SDK 和路线数据 |
| 地点详情 | 核心页面，展示来源、营业信息、更新时间和推荐原因 |
| 调整行程 | 核心页面，真实锁定与替换必须重新校验时间和路线 |
| 发现 | 只做少量人工主题，不建设推荐内容流 |
| 我的 | 先做保存行程和偏好，收藏、账户中心和跨设备同步后补 |

原型首页的内部标识是 `discover`，发现页是 `explore`；这些只是原型实现命名，不要求正式应用照搬。

## 运营后台

| 原型模块 | 首版如何使用 |
| --- | --- |
| 运营总览 | 延后；后台可直接进入地点列表 |
| 攻略来源审核 | 保留人工录入、关联和核验；链接先做证据，不承诺自动抓取 |
| 地点与美食库 | 保留地点、坐标、营业信息和核验状态编辑 |
| 路线方案 | 与用户行程合并成简单查看，不建设独立模板发布系统 |
| AI 推荐规则 | 简单权重/时间参数配置；不做版本发布与回滚平台 |
| 用户行程 | 保留生成结果和失败原因查看，不做统计分析系统 |
| 数据分析 | 延后 |
| 服务与设置 | 延后控制台；服务配置先由后端环境变量管理 |

对外开放后台前仍需基本管理员认证。延期的是复杂权限和运营平台，不是把管理接口公开给所有人。

具体首版功能以[产品计划](../product/product-plan.md)为准，实现顺序见[最小实现方案](../architecture/minimal-implementation-plan.md)。
